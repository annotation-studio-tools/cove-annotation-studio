First public release of Annotation Studio for COVE.

- Fast playback and precise boundary controls.
- Overlapping tag intervals, duplicate timing and an unannotated coverage row.
- Collapsible saved-tag groups and an editable timeline.
- Creatable tag selector.
- Portable JSON export, import preview, duplicate detection and scene alignment checks.

Requires COVE 1.7.0 or later; tested with COVE 1.7.0 on Windows and H.264/AAC MP4 files.
Install the ZIP through COVE's extension manager, reload, then choose Annotate on a video.

Known limits: direct-file playback only, no transcoding/VR UI, and additive sequential
imports rather than an atomic multi-user merge. See the README for details.
